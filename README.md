# 📱 Web Publisher Quest - HTML & CSS Project (Quest 1/2)

A responsive, interactive web experience built with HTML5, CSS3, and JavaScript — featuring swipeable slideshows, optimized images, and a mobile-first design approach.

---

## ✨ Features

### 1️⃣ Swipeable Slideshow  
- Fully functional **carousel with swipe gestures** for mobile devices.  
- Users can navigate slides by swiping left or right.  
- The **active slide is dynamically centered and highlighted** for an enhanced user experience.

---

### 2️⃣ Responsive Design  
The layout adjusts seamlessly across various screen sizes:

- **Desktop**: Full-width layout with high-resolution images.
- **Tablet**: Adjusted padding, font sizes, and image dimensions.
- **Mobile**: 
  - Hamburger menu for navigation.
  - Optimized image sizes and spacing.
  - Swipe gestures for carousel navigation.

---

### 3️⃣ Image Optimization  
- **Lazy-loading** implemented for images, loading them only when they approach the viewport.
- Images resized and compressed for faster load times without compromising quality.
- **Modern image formats (WebP)** recommended for future improvements.
- Use of `srcset` and `sizes` attributes for responsive images.

---

### 4️⃣ Use of AI for Faster Workflow  
Leveraged AI tools to:
- Generate boilerplate code for repetitive tasks.
- Optimize CSS and JavaScript for readability and performance.
- Suggest responsive design strategies and image optimization tips.
- Assist with debugging and testing.

---

## 🛠️ Technologies Used  

- **HTML5**: Semantic, accessible markup.  
- **CSS3**: Advanced styling with animations and media queries.  
- **JavaScript (ES6)**: Interactive components like swipe gestures and dynamic slideshows.

## 🎨 Project Highlights  

### 📌 Header & Navigation  
- Fixed navigation bar with a **hamburger menu on mobile**.
- Smooth CSS animations for mobile menu transitions.
- **Backdrop overlay** for mobile nav focus.

### 📌 Hero Section  
- Clean, visually appealing hero section with animated text and images.
- Animations triggered when the section scrolls into view.

### 📌 Third-Div Carousel  
- Swipeable carousel with **smooth sliding effects**.
- Slide indicators and **prev/next buttons** for manual navigation.

### 📌 Sixth-Div Carousel  
- **Infinite scrolling carousel** with cloned items for seamless looping.
- Active item dynamically **centered and highlighted** using border and shadow.

- **Desktop**: Large images, spacious layout.  
- **Tablet**: Adjusted font sizes, padding, and image scaling.  
- **Mobile**:  
  - Hamburger menu.  
  - Touch-friendly carousels with swipe support.  
  - Optimized spacing and text sizes.
