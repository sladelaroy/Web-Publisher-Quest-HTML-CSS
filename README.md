Web Publisher Quest - HTML & CSS Project - Quest 1(1/2)
Features
1. Swipeable Slideshow
Implemented a fully functional carousel with swipe gestures for mobile devices.
Users can navigate through slides by swiping left or right.
The active slide is dynamically centered and highlighted for better user experience.
2. Responsive Design
The layout is fully responsive and adapts seamlessly to different screen sizes:
Desktop: Full-width layout with high-resolution images.
Tablet: Adjusted padding, font sizes, and image dimensions for medium-sized screens.
Mobile: Optimized layout with a hamburger menu, reduced image sizes, and touch-friendly navigation.
3. Image Optimization
All images are optimized for faster loading and better performance:
Lazy-loading is implemented to load images only when they are about to enter the viewport.
Images are resized and compressed to reduce file size without compromising quality.
Modern image formats like WebP are recommended for future improvements.
4. Use of AI for Faster Workflow
AI tools were leveraged to:
Generate boilerplate code for repetitive tasks.
Optimize CSS and JavaScript for better performance and readability.
Provide suggestions for responsive design and image optimization.
Accelerate debugging and testing processes.
Technologies Used
HTML5: Semantic and accessible markup.
CSS3: Advanced styling with media queries for responsiveness.
JavaScript (ES6): Interactive features like swipe gestures and dynamic slideshows.
Project Highlights
Header and Navigation
A fixed navigation bar with a hamburger menu for mobile screens.
Smooth transitions for the mobile navigation menu using CSS animations.
Backdrop overlay for better focus on the mobile menu.
Hero Section
A visually appealing hero section with text and images.
Animations triggered when the section enters the viewport.
Third-Div Carousel
A swipeable carousel with smooth sliding effects.
Indicators to show the current active slide.
Buttons for manual navigation (prev and next).
Sixth-Div Carousel
Infinite scrolling carousel with cloned items for a seamless loop.
Active item is dynamically centered and highlighted with a border and shadow.
Responsive Design
Desktop: Full layout with large images and detailed text.
Tablet: Adjusted padding and font sizes for better readability.
Mobile:
Hamburger menu for navigation.
Reduced image sizes and optimized spacing.
Swipe gestures for carousels.

Lazy-loading: Implemented using the loading="lazy" attribute for all images.
